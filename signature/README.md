# BirrEX Signature

Dependency-free HTML/CSS/JavaScript redesign of the supplied standalone Next.js export. Serve this folder with `python -m http.server 8080` and open http://localhost:8080. Deploy the folder as a static site after review.

The converter and marketplace use illustrative values, not live market data. No authentication, payments, orders, escrow, or wallet functionality is connected. Original claims about licensing, reserves, usage, audits and regulatory compliance are deliberately omitted until verified. Existing repository files are unchanged.

Manual acceptance: check at 360px, 768px and 1440px; verify keyboard navigation, reduced motion, buy/sell, asset and payment filters, offer dialog and nonnegative converter inputs. Browser QA and live deployment are outstanding.
