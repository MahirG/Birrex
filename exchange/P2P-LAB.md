# BirrEX 0.5.0 — P2P Experience Lab
Fictional merchant profiles, sample verification status, reputation, scripted feedback, search, filters and sorting. Consumer protection exercises include fixed educational communication, clarification, stopping, reporting, simulated review and moderation outcomes. Cases run entirely in browser memory and reset on reload. No real counterparties, listings, actual payments, escrow, contact details, private messages or financial orders. No collection of personal information. Production merchant onboarding, KYC, communication and moderation infrastructure require regulatory and security review before activation. No new paid services or DB tables. Existing D1 identity/market cache and CMC_API_KEY remain unchanged.
